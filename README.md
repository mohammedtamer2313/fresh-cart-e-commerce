# FreshCart - E-Commerce App

A full-featured e-commerce web app built with Next.js and React.

**Live demo:** https://e-commarce-app-orcin.vercel.app/

## Features
- User authentication (sign up, sign in, protected routes)
- Product catalog with categories, brands and search
- Shopping cart with add/remove and quantity updates
- Wishlist
- Checkout with online payment
- Fully responsive design

## Tech stack
- Next.js, React, TypeScript
- Tailwind CSS
- REST API integration (Axios / fetch)
- Context API for cart and auth state

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000
